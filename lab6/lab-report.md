# Grabed Lab
## Objective
In this lab, we deployed a static website to Azure Blob Storage. We set up a storage account, created some basic HTML files in VS Code, and pushed them to Azure using the Storage extension. We also tested that the site was publicly accessible and cleaned up resources to avoid extra charges. The objective of this lab was build a serverless static website using Microsoft Azure Blob Storage.
This lab aims to strengthen foundational cloud development skills, introduce serverless hosting concepts, and demonstrate how to use development tools to deploy web applications to the cloud efficiently.

## Process
1. We created a storage account in Azure and enabled static website hosting.
2. We created an index.html file and a 404.html file locally in VS Code.
3. We used the Azure Storage extension in VS Code to deploy the HTML files to the $web container in our storage account.(Press "F1" button and follow the instructions)
4. We verified that the website was publicly accessible by navigating to the provided URL.
5. Finally, we cleaned up resources by deleting the storage account to avoid unnecessary charges.

## Final observations and learning outcomes
Through this lab, we learned how to deploy a static website using Azure Blob Storage. We gained hands-on experience with Azure Storage accounts, enabling static website hosting, and using development tools like VS Code to manage and deploy our web content. This lab reinforced our understanding of serverless hosting concepts and the ease of deploying web applications to the cloud without managing infrastructure.
